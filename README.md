# Valheim-Guide

Progressions-Guide für Valheim (PS5): Biom für Biom, Boss für Boss. Fortschritt lokal im Browser, kein Account.

Live: https://marlonzag97.github.io/valheim-guide/

```bash
npm install
npm run dev      # http://localhost:5173/valheim-guide/
npm run check    # Typen, Lint, Daten, Tests
```

Inhalt liegt unter `inhalt/<nn-biom>/daten.json` (Werte) und `guide.md` (Prosa, sechs feste H2). Spielversion: `inhalt/VERSION.md`.

Fan-Projekt, kein offizielles Produkt von Iron Gate oder Coffee Stain. Keine Spiel-Assets im Repo.
